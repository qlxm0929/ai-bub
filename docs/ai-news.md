# AI 소식·무료 혜택 운영

- `/news`: 새 소식·혜택, `/news?tab=news`: 기존 뉴스, `/news?tab=youtube`: 기존 YouTube.
- `/api/discovery`: 실제 공식 RSS·개발자 릴리스·요금 문서를 조회한다. 최대 5분 동일 수집 결과를 공유한다. 요청이 있어야 수집하며 알림·예약 수집은 없다.
- 수집 시각과 게시일은 별개다. 실패한 소스는 성공 시각을 갱신하지 않는다. 브라우저에 이전 결과가 있으면 실패한 소스의 자료만 보존하고 이전 자료라고 표시한다.
- 가격 검증은 `src/lib/discovery/catalog.ts`의 공식 URL과 필수 문구를 기준으로 한다. 필수 문구가 바뀌면 검증 실패로 전환한다. 주기적인 운영자 검토를 대체하지 않는다.
- 현재 무료 근거: GitHub Copilot Free, Gemini API 무료 티어. 무료 체험: Google Cloud 신규 사용자 크레딧. 카드·종료 조건은 근거가 확보된 항목만 표시한다.
- 오픈소스 여부는 자동 추정하지 않는다. Hugging Face 커뮤니티 글은 공식 발표와 구분한다.
- Product Hunt, Threads, Instagram은 미연결 상태를 명시한다. 인증·검색 서비스와 이용 조건 검토 후 어댑터를 추가해야 한다.
- 즐겨찾기는 이 브라우저에 최대 200개 보관한다. 계정 동기화는 없다. 저장소 차단·용량 오류는 사용자에게 알린다.

## 한국어 요약

기존 번역 함수 결과에 한국어가 없으면 기존 `GEMINI_API_KEY` 설정으로 원문 발췌를 한국어 요약한다. 기본 모델은 기존 앱과 같은 `gemini-2.5-flash`, `NEWS_SUMMARY_MODEL`로 변경 가능하다. 가격·날짜·무료 자격은 모델이 결정하지 않는다. 모델에 전달되는 내용은 공개 원문의 제목과 짧은 발췌뿐이다.

동일한 발췌 묶음은 24시간 요약 결과를 재사용한다. 요약 실패는 수집 상태에 표시하고 원문으로 대체한다. Gemini API 요금은 연결된 계정의 요금제·쿼터를 따른다. 키는 서버 환경 변수로만 사용하며 브라우저로 전달하지 않는다.

## 확인 방법

`npm ci`, `npm run build`, `npx tsc --noEmit` 후 `npm start`로 실행한다. 새 탭에서 무료 플랜·무료 체험·검색·저장 후 재접속·기존 뉴스·YouTube를 확인한다. 조회 실패 검증은 운영 소스를 차단하지 말고 별도 로컬 HTTP 검증 환경에서 수행한다.

## SNS AI 선별 탭

`/news?tab=social`은 `src/lib/social/catalog.ts`에 직접 선별한 공개 게시글을 보여줍니다. 자동 수집 결과가 아닙니다. 2026-09-16에 Threads 3개, Instagram 3개 원문/캡션과 게시일을 브라우저로 확인했습니다. 이미지·영상 내용 전체를 복제하지 않고 짧은 한국어 요약과 원문 링크를 제공합니다.

게시글을 추가할 때 원문 URL, 작성자, 게시일(불명은 null), 확인일, 주제, 주의사항을 함께 기록하세요. 원문 URL이 같으면 중복 등록하지 않습니다. 출처 게시일로 내림차순 정렬해 등록하며, 확인일을 게시일처럼 사용하지 않습니다. 오래된 무료 체험 소개는 `무료 언급`으로만 분류하고 현행 조건 미확인을 명시합니다.

플랫폼/분야/키워드 필터와 브라우저별 저장을 지원합니다. 검색 링크는 Google에서 해당 SNS 도메인과 AI 키워드로 검색하며 로그인이나 신규 API 비용이 필요하지 않습니다. 검색 결과 및 원문 접근 범위는 제공 플랫폼에 따릅니다. 선별 자료를 새로고침했다고 원문을 다시 수집했다고 표시하지 않습니다.

## SNS 자동 수집 설정
- 서버 환경변수 `TAVILY_API_KEY`를 설정하면 `/api/social`이 실제 Tavily Search를 호출한다. 키를 `NEXT_PUBLIC_` 변수나 소스 파일에 넣지 않는다.
- 개발: 원본 `.env.local`에 설정 후 개발 서버 재시작. 운영: Vercel의 ai-bub 프로젝트 → Settings → Environment Variables → Production에 추가 후 재배포. 로컬 설정만으로 운영 환경에 반영되지는 않는다.
- 키 미설정은 HTTP 503 + `delivery: unconnected`, 플랫폼별 미연결. 선별 카드와 원문 검색은 계속 제공한다.
- 탭 진입/브라우저 새로고침/수집 버튼에서 API를 조회한다. 서버는 고정된 10분 구간의 결과를 공유한다. 구간 안에서는 외부 검색을 다시 수행하지 않으며 UI에 저장 결과임을 표시한다. 클라이언트 임의 검색어를 서버 검색 쿼리에 전달하지 않는다.
- 각 실제 수집은 플랫폼별 `basic` 검색 두 건, 재시도 없음, 최대20결과씩. 사용량은 Tavily 계정 설정에서 확인하고 한도를 지정한다. 키 설정 전 유료 자동 충전 여부를 확인한다. 429/432/433은 한도 오류로 표시한다.
- `time_range: month`는 검색 서비스의 게시/갱신일 기준이다. 날짜 없는 결과는 배제하지 않으며 제공된 게시일만 표시한다. 추정 날짜를 만들지 않는다.
- Threads com/net 및 Instagram의 p/reel 게시글 주소만 허용한다. 프로필·로그인·검색 페이지·다른 도메인은 제외한다. URL의 게시글 코드로 중복 제거한다. 제목/검색 발췌에 AI 관련 표현이 없는 글은 제외한다. 키워드 분류는 완벽한 의미 판별이 아니므로 원문 확인이 필요하다.
- 검색 발췌는 원문 전체 확인/공식 제품 확인을 뜻하지 않는다. 무료 언급도 가격 확인으로 승격하지 않는다. SNS 전체 스트림 또는 비공개 게시글 수집 기능이 아니다.
- 플랫폼 한쪽 실패는 그 플랫폼의 이전 결과만 유지한다. 성공한 빈 결과는 해당 플랫폼의 이전 자동 결과를 비운다. 기존 선별 글과 북마크는 별도 보존한다. 브라우저 저장 실패는 사용자에게 알린다.
- 제공자 문서: https://docs.tavily.com/documentation/api-reference/endpoint/search
